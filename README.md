# 🛡️ CyberBuddy AI — AI-Powered Cybersecurity Assistant

> **Learn. Detect. Protect.**

CyberBuddy AI is an intelligent cybersecurity assistant designed to educate users on core security concepts, analyze potential phishing threats (suspicious URLs & emails), and provide actionable online safety guidance.

---

## 🚀 Key Features

* **🤖 AI Cybersecurity Assistant:** Interactive AI chatbot to answer security queries, explain technical terms (malware, encryption, firewalls), and provide best-practice recommendations.
* **🔍 Phishing Detection System:** Pattern-based and heuristic analyzer for inspecting suspicious links and email text for credential harvesting signals.
* **🛡️ Online Safety Advisor:** Recommendations for password policies, multi-factor authentication (MFA/2FA), and social media protection.
* **📊 Interactive Security Dashboard:** Dark navy cybersecurity interface built with Streamlit.

---

## 🛠️ Tech Stack & Architecture

* **Frontend / Dashboard:** Streamlit
* **Language:** Python 3.10+
* **AI Engine:** Google GenAI / Groq API
* **Version Control:** Git & GitHub
